# 项目入口模板

[模板目录](README.md)

使用说明：按自己项目的事实改写后，可作为项目 `AGENTS.md` 的起点。此文件中的示例不代表当前仓库有相应系统或验证能力。填写真实路径时优先使用相对链接，并验证可达。

## 项目目标

待填写：系统服务谁，完成什么用户结果，哪些业务能力明确不在范围内。

## 事实路由

| 任务或问题 | 唯一维护位置 |
| --- | --- |
| 业务范围与口径 | 待填写 |
| 组件职责与实现契约 | 待填写 |
| 安全边界与验证要求 | 待填写 |
| 当前状态、有效版本与授权 | 待填写 |

已有信息充分时直接执行；先查证项目中能找到的事实，只询问影响结果或授权的未决事项。

## 完成原则

按用户结果确定范围，检查直接调用方、相关状态和同类入口。已有证据且风险可控的关联修复可以一并完成。涉及新业务能力、既定口径变化、破坏性动作或未授权外部影响时，先明确决定。

## 不可降级边界

待填写：具体禁止动作、数据保护、凭据处理与环境限制。每条高风险约束同时指向对应执行机制；没有机制的部分明确说明。

## 验证入口

待填写：项目实际存在的命令、范围选择、失败与跳过处理、必要的用户路径验收。不要粘贴当前工程无法执行的示例命令。

## 交付与记忆

只报告实际完成的验证；说明关键取舍和未覆盖部分。稳定规则进入领域文档；当前交接替换过时事实；已完成过程进入历史记录。
