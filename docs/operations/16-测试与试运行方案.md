# 测试与试运行方案

[运维索引](index.md) · [统一质量门禁](../engineering/QUALITY.md)

## 分层而不混淆

| 层级 | 输入与环境 | 主要证明 |
| --- | --- | --- |
| 文档与静态 | 仓库、链接、受检源码与脚本 | 契约可达，受检边界未违规 |
| 单元与组件 | 可控输入和时钟 | 状态、算法、幂等和错误行为 |
| 隔离集成 | 本机数据库、回环 API、模拟主机 | 组合后的事务和恢复路径 |
| 真实系统服务 | 经授权的随机隔离服务 | 服务管理器、退出码和恢复行为 |
| 浏览器验收 | 模拟 API 与实际操作 | 查询、保存、权限和视觉状态 |
| 现场试运行 | 已授权设备和当次版本 | 实际协议、网络、硬件与使用路径 |

## 用失败场景设计验收

采集验证缺测、非有限值、读组失败和周期超时；持久化验证写入失败、重启和确认丢失；报警验证重复与孤立恢复；部署验证状态过渡、路径不匹配、旧心跳和提交结果未知；维保验证并发领取、版本冲突、弱网与禁止自审。

## 现场只读边界

基础连通、单点读取、完整点集扫描、HMI 对照和原系统是否受影响分步确认。新增点位、周期或程序不能直接复用旧配置的历史结论。

手机维保需要实际手机、可信连接、摄像头与网络；桌面模拟摄像头只支持本机流程验证。服务恢复也需区分模拟命令、真实隔离服务与现场采集器。

## 记录格式

记录对象、版本、输入、环境、执行时间、期望、实际结果和证据位置。结果区分通过、失败、跳过和未运行。测试数量只解释覆盖范围，不作为代码质量或个人贡献的简单分数。

## 实施时如何使用

本页用于规划测试分层和验收材料。实施时应为当次版本填写执行结果；文档链接与图表检查只说明文档质量，不替代应用或环境验证。
