# 参考资料与选型依据

[参考索引](index.md)

参考资料用来帮助比较方案。目录组织、系统边界与验收策略是本文档给出的设计建议，不是工具强制要求。

## 选型应回答的问题

| 选择 | 在本方案中的考虑 | 重审条件 |
| --- | --- | --- |
| .NET 与 ASP.NET Core | 统一采集与中心服务技术体系，明确宿主和生命周期 | 设备 SDK、部署平台或团队条件不同 |
| SQLite | 边缘本地事务与重启恢复 | 多写入者、容量和磁盘约束变化 |
| SQL Server | 关系约束、事务、窗口查询与运维能力 | 成本、许可、规模或运维技能变化 |
| Vue 与 Vite | 按页面和状态组织交互，保持构建链清晰 | 团队经验、生态与目标终端变化 |
| PowerShell | Windows 服务和本机流程的自动化入口 | 跨平台范围扩大，工具兼容条件变化 |
| AGENTS.md 与分类知识库 | 提供任务路由、约束和稳定上下文 | 使用的代理工具、任务形态或知识规模变化 |

选型应结合可验证收益、迁移成本和恢复难度。不能仅因 AI 熟悉某个框架，就将它当成业务要求。
