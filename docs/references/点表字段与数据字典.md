# 点表字段与数据字典

[参考索引](index.md)

本页给出建议的字段职责与虚构示例。具体导入格式应与协议、校验规则和版本管理保持一致。

## 资产与连接

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| equipment_code | 设备稳定编码 | 示例 DEMO-001 |
| equipment_name | 显示名称 | 示例设备，不用于替代稳定身份 |
| factory / line / stage / process | 完整组织路径 | 同名末级节点不代表同一组织 |
| protocol_code / transport_mode | 协议与传输类型 | 必须匹配实际支持集合 |
| connection parameters | 协议地址、端口、槽位等 | 由所选协议与接入环境决定 |

## 点位

| 字段 | 职责 | 常见误解 |
| --- | --- | --- |
| address | 机器读取地址 | 显示名称变化不能自动改地址 |
| point_name | 业务可读名称 | 通常不替代点位身份，特定状态角色有明确契约 |
| data_type | 值如何解码 | 不能由显示内容猜测 |
| point_type | 报警、状态、参数等 | 决定保存与上送语义 |
| cycle_ms | 采集调度周期 | 不等于 UI 刷新或每次全量上传 |
| collector_enabled | 是否进入生成的采集配置 | 不是故障统计分类 |
| is_excluded_from_fault | 是否排除故障统计 | 排除后仍可作为原始报警展示 |
| description | 点位业务说明 | 报警开始时保存快照供历史解释 |

## 身份与历史

设备编码和地址共同定位点位。保留历史关联的停采点宜保留在完整点集中并关闭采集；通过删行表达停采可能影响历史查询关联，必须遵守导入契约。

## 时间与版本

collected_at、event_time、uploaded_at、received_time、processed_time 各自承担不同时间语义。config_version 与 program_version 各自表示配置和程序身份。任务 version 用于并发检查，requestId 用于命令重试，这四种标识不能混成一个字段。

## 接收与业务处理

原始事件可靠入箱、生命周期处理完成、页面查询成功是三个不同阶段。诊断和验收必须能指出延迟发生在哪一层，而不是只有一个笼统的“数据正常”。
