# Web 操作记录与审计

[设计索引](index.md)

## 记录什么

记录时间、模块、对象、实际变化、操作人身份快照与结果。身份由服务器验证，不能采用浏览器提交的显示名称。后续人员改名或删除，不重写历史责任。

范围覆盖明确接入的 Web 业务动作，不声称自动记录直接 SQL 或所有外部运维操作，也不追补系统启用前的历史。

## 事务型变更

分类、统计规则等业务修改与操作记录在同一事务提交。实际旧值由数据库修改结果取得，不用前端保存前的缓存冒充。无变化不新增日志，非法批量整体回滚。

这种做法避免出现“界面声称已修改，但数据库没变”或“数据变了却没留下责任记录”的局部提交。

## 后台与远程任务

排队时保存操作者，远程动作前持久化记录，结束后补充状态。导入差异代表操作意图；部署成功、回退成功、未知或失败分别记录。

如果结果记录失败，不应重新执行远程动作。中心中断时保留待核实结果，不能因为缺少完成日志就推断操作没有发生。

## 可见内容与保留

只允许明确的业务配置字段进入差异。请求体、凭据、连接串和远端原始输出不能无筛选地落入审计或前端。查看记录有独立权限，写入记录仍由对应业务权限控制。

记录查询按稳定时间和 ID 排序，采用明确的时间边界和分页。长期保留与备份是两种能力，不能把“没有自动删除”写成“已有可靠备份”。

## 验收

并发修改读取实际旧值、无变化不重复、业务回滚时日志同步回滚、后台身份不串号、敏感字段不泄漏，以及中心中断后的状态展示，都应具备相应证据。
