# 安全门禁与操作边界

[工程索引](index.md)

安全规则应进入任务入口、工具约束与验证设计，并与环境权限配合。以下给出只读采集场景的建议边界。

## PLC 永远只读

本方案限定为已批准点位的只读采集，建议禁止写点、控制以及不在允许集内的 Browse、Write、Subscribe 类调用。这里的允许集是设计选择，不意味着所有协议中的同名 API 都有相同设备副作用。不能确认只读性质时，不以测试为理由探索。

检查器递归检查受检生产源码中的禁止调用；回归覆盖嵌套目录，避免顶层扫描遗漏。静态识别不是设备安全认证，协议语义、其他调用路径与运行权限仍需核实。

## 普通验证与生产操作分开

常规 verify 只用本机、临时目录、模拟接口和回环地址，不访问生产中心、网关或 PLC。脚本入口通过语法树核对字面量命令和脚本允许集，拒绝无法静态确认的动态目标。

该机制不是 PowerShell 沙箱，被调用内容和环境权限仍要审阅。不能把允许调用一个脚本解释为该脚本所有行为都已获外部授权。

## 生产任务的授权

明确对象、动作、有效范围和验收。已授权且目标未变的步骤可连续完成，不逐步重复询问；新增破坏性动作、整机重启或目标变化需要重新核对。普通开发不自动部署。

## 采集停止屏障

协作完成当前扫描与已完成批次落盘，服务进入 Stopped 后再切换程序或重启。超时与 StopPending 不构成停止成功；不能强杀或通过删除缓存解除等待。中心未收到的已落盘记录不阻塞安全停机。

## 凭据与日志

密码、私钥和数据库密码不进入 Git、文档、包、命令回显或日志。远程错误、原始请求和点表单元格也不能未经筛选回显。临时凭据与现场证据放受控位置，不能被公开发布流程拾取。

## 失败恢复

先核实数据库提交、服务路径、文件和版本，再决定动作。响应失败不表示远端未执行，状态不可读也不能被写成成功。保留未解决任务与证据，禁止用无限重试掩盖不确定性。
