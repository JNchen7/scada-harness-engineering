# 方案定位与使用

[知识库](README.md)

这是一份以 SCADA 与设备管理为场景的个人技术方案，表达我认为需求、架构、AI 协作、质量和交付应该怎样组织。目标是提供可讨论、可调整的设计建议，展示规划能力和 Harness Engineering 应用思路。

## 内容如何阅读

产品规格描述目标与边界；详细设计说明数据和状态契约；工程规则规划开发约束；运维文档给出交付方法；问题推演解释失败分支；模板帮助把方法用于具体任务。

文中的“建议采用”“应满足”和状态规则是方案主张。容量数字、接口标识和时间区间是说明性示例。技术选择有适用条件，使用时应根据规模、环境和业务规则调整。

## 如何用于自己的项目

1. 先明确用户目标、范围、设备边界和验收标准。
2. 按约束挑选相关模块，比较替代方案和维护成本。
3. 建立最小知识入口与验证闭环，再拆解实施任务。
4. 用失败场景检验契约；实际执行后记录结果和覆盖范围。
5. 将稳定决定与当前状态分别维护。

本仓库提供文档与内嵌图表。运行代码、部署工具和应用验证需要在具体实施时建设。配套 [评审清单](portfolio/方案评审与验证清单.md) 用于判断方案完整性和规划验证。
